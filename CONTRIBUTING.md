# Contributing to My Modchart Repositories

Thank you for your interest in contributing! Your help is appreciated, whether it's fixing bugs, improving charts, or adding new mod features.

Please read this guide carefully to make contributions smoother for everyone.

---

## How to Contribute

### 1. Reporting Issues
- Use the **Issues** tab to report bugs or request features.  
- Provide clear, concise details:
  - What you expected  
  - What happened instead  
  - Steps to reproduce  
  - Screenshots or logs if applicable  

> **Note:** Security vulnerabilities should **not** be reported publicly. See [SECURITY.md](SECURITY.md) for reporting guidelines.

### 2. Submitting Pull Requests
- Fork the repository to your account.  
- Create a new branch for your changes, for example:  
  git checkout -b feature/your-feature-name  
- Make your changes.  
- Test thoroughly in the Psych Engine environment.  
- Submit a pull request to the `main` branch.

**Pull requests should include:**
- A clear title  
- Description of what the change does  
- Screenshots or examples if applicable  

### 3. Coding & Style Guidelines
- Lua scripts should follow standard Lua conventions.  
- Keep code readable and well-commented.  
- Avoid making unrelated changes in the same pull request.  
- Follow the existing file structure.

### 4. Chart Submissions
- Charts must be tested in-game before submission.  
- Include **any custom assets** you created (sprites, sounds, etc.) or provide clear credit if using third-party assets.  
- Do not submit charts that violate copyright or the license of the repository.

---

## Community Guidelines
- Be respectful and constructive in all communications.  
- Treat all contributors fairly.  
- Avoid spammy or low-quality contributions.
